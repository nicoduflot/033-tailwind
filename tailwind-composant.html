Tailwind CSS Avancé

Modules, @apply et Extraction de composants

📦 1. Création de Modules

Qu'est-ce qu'un module Tailwind ?

Un module est un fichier CSS séparé qui contient des composants réutilisables. Il permet d'organiser votre code et de créer une bibliothèque de composants personnalisés.

📁 Structure de fichiers recommandée

// Structure du projet 
src/
├── css/
│   ├── main.css          // Fichier principal
│   └── components/       // Dossier des modules
│       ├── buttons.css
│       ├── cards.css
│       └── forms.css
└── tailwind.config.js

📝 Exemple : main.css

@tailwind base;
@tailwind components;
@tailwind utilities;

/* Importer vos modules */
@import './components/buttons.css';
@import './components/cards.css';
@import './components/forms.css';

📝 Exemple : components/buttons.css

/* Module dédié aux boutons */
@layer components {
  .btn {
    @apply px-4 py-2 rounded font-semibold transition duration-200;
  }

  .btn-primary {
    @apply btn bg-blue-600 text-white hover:bg-blue-700;
  }

  .btn-secondary {
    @apply btn bg-gray-600 text-white hover:bg-gray-700;
  }

  .btn-outline {
    @apply btn border-2 border-blue-600 text-blue-600 hover:bg-blue-50;
  }
}

🎨 2. L'outil @apply

Qu'est-ce que @apply ?

@apply permet d'extraire des classes utilitaires Tailwind répétitives dans des classes CSS personnalisées. C'est comme créer des "raccourcis" pour des combinaisons de classes fréquemment utilisées.

❌ Sans @apply (répétitif)

<!-- Répété partout dans le HTML -->
<button class="bg-blue-600 hover:bg-blue-700 text-white font-semibold py-2 px-4 rounded-lg transition duration-200 shadow-md">
  Cliquez-moi
</button>

<button class="bg-blue-600 hover:bg-blue-700 text-white font-semibold py-2 px-4 rounded-lg transition duration-200 shadow-md">
  Encore moi
</button>

✅ Avec @apply (propre)

/* Dans votre CSS */
@layer components {
  .btn-primary {
    @apply bg-blue-600 hover:bg-blue-700 text-white 
           font-semibold py-2 px-4 rounded-lg 
           transition duration-200 shadow-md;
  }
}

<!-- Dans votre HTML (beaucoup plus propre) -->
<button class="btn-primary">Cliquez-moi</button>
<button class="btn-primary">Encore moi</button>

🎯 Démonstration Live

☝️ Les deux boutons ont le même style, mais le premier utilise une classe créée avec @apply

⚠️ Bonnes pratiques avec @apply

  • Utilisez @layer components pour garder la cascade CSS correcte
  • N'abusez pas de @apply : gardez l'esprit utility-first de Tailwind
  • Réservez @apply pour les composants vraiment réutilisés
  • Évitez @apply pour des variations uniques

📚 Exemple complet : Card component

/* components/cards.css */
@layer components {
    .card {
        @apply bg-white rounded-lg shadow-lg p-6
        border border-gray-200
        hover:shadow-xl transition-shadow duration-300;
    }

    .card-title {
    @apply text-2xl font-bold text-gray-900 mb-3;
    }

    .card-text {
    @apply text-gray-600 leading-relaxed mb-4;
    }

    .card-footer {
    @apply border-t border-gray-200 pt-4 mt-4
    flex justify-between items-center;
    }
}

🔄 3. L'Extraction de Composants

Qu'est-ce que l'extraction ?

L'extraction consiste à identifier des patterns répétitifs dans votre HTML et les transformer en composants réutilisables. Il existe 3 niveaux d'extraction.

🎯 Niveau 1 : Extraction en composant HTML/Template

La méthode la plus simple : créer des composants/partials dans votre framework (React, Vue, etc.)

❌ Avant (répétitif)

<!-- Page 1 -->
<div class="bg-white rounded-lg shadow p-6">
<h3>Titre</h3>
<p>Contenu</p>
</div>

<!-- Page 2 -->
<div class="bg-white rounded-lg shadow p-6">
<h3>Autre titre</h3>
<p>Autre contenu</p>
</div>

✅ Après (composant)

<!-- Card.html -->
<div class="bg-white rounded-lg shadow p-6">
<h3>{{ titre }}</h3>
<p>{{ contenu }}</p>
</div>

<!-- Utilisation -->
<Card titre="Titre" contenu="Contenu" />
<Card titre="Autre" contenu="Autre" />

🎯 Niveau 2 : Extraction avec @apply

Quand les classes sont vraiment répétées partout et qu'un composant ne suffit pas 

/* Dans votre CSS */
@layer components {
    /* Extraction d'un pattern commun */
    .section-container {
    @apply max-w-7xl mx-auto px-4 py-12 md:py-16 lg:py-20;
    }

    .section-title {
    @apply text-3xl md:text-4xl lg:text-5xl font-bold
    text-gray-900 mb-6 text-center;
    }

    .section-description {
    @apply text-lg text-gray-600 text-center
    max-w-3xl mx-auto mb-12;
    }
}

<!-- Utilisation (beaucoup plus propre) -->
<section class="section-container">
<h2 class="section-title">Nos Services</h2>
<p class="section-description">
Description de nos services...
</p>
</section>

🎯 Niveau 3 : Extraction avec variantes

Créer un système de composants avec variantes et modificateurs 

/* Système de boutons avec variantes */
@layer components {
    /* Classe de base */
    .btn {
        @apply inline-flex items-center justify-center
        px-4 py-2 rounded-lg font-semibold
        transition duration-200 cursor-pointer
        disabled:opacity-50 disabled:cursor-not-allowed;
    }

    /* Variantes de couleur */
    .btn-primary {
    @apply btn bg-blue-600 text-white
    hover:bg-blue-700 active:bg-blue-800;
    }

    .btn-secondary {
    @apply btn bg-gray-600 text-white
    hover:bg-gray-700 active:bg-gray-800;
    }

    .btn-danger {
    @apply btn bg-red-600 text-white
    hover:bg-red-700 active:bg-red-800;
    }

    /* Variantes de taille */
    .btn-sm {
    @apply px-3 py-1 text-sm;
    }

    .btn-lg {
    @apply px-6 py-3 text-lg;
    }

    /* Variantes de style */
    .btn-outline {
    @apply btn border-2 bg-transparent;
    }

    .btn-outline.btn-primary {
    @apply border-blue-600 text-blue-600
    hover:bg-blue-50;
    }
}

<!-- Utilisation avec combinaison de classes -->
<button class="btn-primary">Normal</button>
<button class="btn-primary btn-sm">Petit</button>
<button class="btn-primary btn-lg">Grand</button>
<button class="btn-outline btn-primary">Outline</button>

💡 Quand extraire ?

  • Pattern répété 3+ fois → Envisagez l'extraction
  • Composant d'UI standard (bouton, card) → @apply ou composant
  • Variation unique → Gardez les classes inline
  • Système complexe (design system) → Extraction avancée avec variantes

📊 Comparaison des approches

Classes Inline

✅ Avantages :

  • Très flexible
  • Pas de CSS séparé
  • Facile à modifier

❌ Inconvénients :

  • Répétitif
  • HTML verbeux

@apply

✅ Avantages :

  • HTML propre
  • Réutilisable
  • Maintenable

❌ Inconvénients :

  • CSS séparé
  • Moins flexible

Composants

✅ Avantages :

  • Très réutilisable
  • Logique incluse
  • Props dynamiques

❌ Inconvénients :

  • Plus complexe
  • Framework requis

🎯 Exercice Pratique

Mission

Créez un système de notifications (alerts) avec 3 variantes : success, warning, error. Utilisez @apply pour créer des classes réutilisables.

Spécifications :

  • Classe de base .alert avec padding, bordure arrondie, etc.
  • Classe .alert-success (vert)
  • Classe .alert-warning (orange)
  • Classe .alert-error (rouge)
  • Incluez une icône et un bouton de fermeture
/* Votre code ici */
@layer components {
.alert {
@apply /* À compléter */;
}

.alert-success {
@apply /* À compléter */;
}

/* ... */
}
